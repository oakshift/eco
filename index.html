Comparação com o carro

O CO₂ é calculado pelos litros não gastos: cerca de 2,68 kg por litro de gasóleo, 2,31 de gasolina e 1,66 de GPL (só o escape; valores aproximados). O desgaste inclui pneus, travões, óleo e revisões. As alterações aplicam-se a todas as viagens, também às antigas.

Onde se guardam os dados

Como criar o token do GitHub
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Dê-lhe um nome, por exemplo eco, e escolha a validade máxima.
  3. Em Repository access, escolha Only select repositories e selecione descomplica-dados.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Carregue em Generate token, copie-o e cole-o aqui. Faça isto em cada dispositivo que usar.

Se o Descomplica já estiver ligado neste navegador, a Eco usa a mesma ligação e não é preciso fazer nada.

O token fica guardado só neste navegador.
