# Eco

O que se poupa em dinheiro, água e CO₂ com hábitos mais ecológicos: sanita seca (um toque por utilização), compostor (um toque por balde despejado), viagens de bicicleta face ao carro e colheitas da horta, com a evolução mês a mês.

- App: https://oakshift.github.io/eco/
- Os dados ficam nos dados do [Descomplica](https://github.com/oakshift/descomplica) (`bicicleta`, `sanita` e `composto`), num repositório privado à parte, lido e escrito com um token do GitHub guardado só no navegador. Se o Descomplica já estiver ligado neste navegador, a Eco usa a mesma ligação.
- A horta é só lida, a partir dos dados do [Caderno da Horta](https://github.com/oakshift/horta).
